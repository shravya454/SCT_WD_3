# Quiz Game Application

## Interactive Stopwatch Timer

A clean, fully responsive quiz application built with HTML, CSS, and JavaScript.

---

## Features

* Interactive quiz system with single-select and multi-select questions
* Real-time score tracking with animated progress bar
* Instant correct and incorrect answer feedback
* Fully responsive modern UI with smooth transitions
* Final result dashboard with answer review and retry option 

---

## Technologies Used

* HTML5
* CSS3
* JavaScript
