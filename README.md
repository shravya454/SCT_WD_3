# Quiz Game Application

## Interactive Stopwatch Timer

A clean, fully responsive quiz application built with HTML, CSS, and JavaScript.
---

## Features

* Fixed two-column layout — stopwatch on the left, lap records on the right
* Start, pause, and reset the timer
* Lap tracking with individual lap time and total time
* Animated SVG progress ring
* Smooth transitions and animations
* Clean and modern UI

---

## Technologies Used

* HTML5
* CSS3
* JavaScript
